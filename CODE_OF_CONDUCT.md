# Code of Conduct

This project exists to make development less painful. That applies to how we treat each other too.

## Expected

- Be patient with people at every skill level. Many contributors are self-taught.
- Critique code and ideas, never people.
- Assume good faith; ask before concluding.
- Respect accessibility needs. Nobody has to justify asking for calmer output, larger text, or a different format.
- Credit others' work, including work done with AI assistance.

## Not accepted

- Harassment, insults, or personal attacks.
- Discriminatory language or jokes.
- Mocking someone's hardware, background, disability, or experience level.
- Publishing others' private information.
- Sustained disruption of discussions.

## Enforcement

Report problems privately to the maintainer (see GOVERNANCE.md for contact). Reports are kept confidential. The maintainer may warn, remove content, or ban participants in proportion to the harm.

Projects wanting a fuller, widely used text may adopt the Contributor Covenant: https://www.contributor-covenant.org/

## No coder left behind

- There are no "noob problems" here. If it hurt, it counts.
- Answer the question that was asked, at the level it was asked.
- "Just read the docs" is only an answer when you link the exact section, and if the docs didn't help, the docs have a pain point.
- Human contributors and AI-assisted contributors are held to the same standard of respect and the same standard of evidence.

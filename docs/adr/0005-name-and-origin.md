# ADR 0005: Name and origin

Status: accepted · 2026-09-17

**Decision.** The project is **Pain Point Resolver** (`pain-point-resolver`, command `ppr`). It supersedes ForgeDoc 1.0.0 (a Termux shell script), whose features are rebuilt as `docs`, `hunt`, `doctor` and the pattern data. The `forge` command name used in early sketches is not used, to keep this public tool distinct from other, unrelated projects.
